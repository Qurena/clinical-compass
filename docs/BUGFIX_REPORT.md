## Не исправлено (требует решения команды)

- Демо-пароль `demo` у всех пользователей: сайт в локальной сети доступен любому, кто знает адрес. Для публичного показа нужен отдельный режим входа.
- Сессии хранятся в памяти и не истекают; после перезапуска сервера пациенты вылетают на экран входа (это ожидаемо для прототипа).
- Числа на постере (доставка алерта 2,9 мс, открытие карточки 2,3 мс) не совпадают с `npm run measure` на этом ноутбуке (16,6 и 15,5 мс медиана). Перед печатью постера числа нужно обновить и описать стенд.
- Шрифты интерфейса грузятся с Google Fonts: без интернета на устройстве сайт откроется со шрифтами по умолчанию.
- Реестр CT13 (резервный получатель) и CT18 (отзыв согласия) по-прежнему не реализованы.
