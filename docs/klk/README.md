# КЛК: «Клинический компас | Медицинская часть»

Общий контекст проекта. Файл `KLK_medical_part.pdf` (17 страниц, скан) — первоисточник логики для опросника, правил маршрутизации, статусов взаимодействий и тестов. Клинические решения принимает Арина; всё, что в прототипе отражено по документу, помечено «требует верификации».

## Что внесено в репозиторий

| Тема КЛК | Где в коде |
|---|---|
| Полный PHQ-9 и HADS-A, раздельные суммы, без «эквивалентов» | `config/sppvr.json`, `src/engine.js` (`scoreSppvr`) |
| Пункт 9 > 0 — отдельный сигнал безопасности, вопрос C7 сразу после ответа | `src/service.js` (`submitSppvr`, `submitClinical`), `public/app.js` (`drawC7`) |
| ИКСО (вспомогательный индекс качества), штрафы A/C/T/P | `config/sppvr.json` (`quality`), `scoreSppvr` |
| Формулировка «Нетипичное время: уточнить ответы» вместо «социальной желательности» | `public/app.js`, `config/rules.json` |
| Клинический блок C1–C12, «не знаю» ≠ «нет» | `config/sppvr.json`, `deriveClinical`, экран «О здоровье» |
| Авиандр только после диагноза врача; рекомендация — «рассмотреть», не рецепт | `src/protocol.js` (`aviandrAdvice`), `config/plans.json` |
| ИМАО — жёсткая блокировка; серотонинергические — оранжевый; неизвестное — серый | `config/ddi.json`, `checkDrug` |
| Маршруты НЕОТЛОЖНО / ОБЯЗАТЕЛЬНО / РЕКОМЕНДОВАНО, 26 правил | `config/rules.json`, `evaluateReferral` |
| Госпитализация не назначается автоматически; красный алерт ничего не блокирует | `config/rules.json`, `public/app.js` |
| Статусы алерта: создан → доставлен → открыт → принят → действие | `src/service.js` (`ackAlert`), `public/app.js` (`chain`) |
| Решение врача по рекомендации: подтвердить / изменить / отклонить с причиной | `recordAdvice`, `POST /api/doctor/patients/:id/advice` |
| Реестр тестов T-01…T-25 и три сквозных случая | `test/klk.test.js` |

## Оставлено Арине (не решалось в коде)

- Лицензия HADS и валидированная русская форма (в демо подпись «до проверки лицензии»).
- Окончательные пороги и формулировки: 11/8 для HADS-A, 10/15/20 для PHQ-9, порог нетипичного времени (4 минуты — гипотеза), штрафы ИКСО.
- Статус сертралина (оранжевый в прототипе), взаимодействия CYP3A4/CYP2D6 и поправки доз бензодиазепинов (в прототипе без числовых значений).
- Позиционирование Авиандра («вторая линия») — нужен источник; ссылки на КР и инструкцию ГРЛС требуют сверки на дату релиза.
- Нумерация вопросов в документе («Q9/Q10»); в тесте T-03 заявлена сумма 22, а вектор даёт 23.
- Телефон приёмного отделения и горячая линия на экране безопасности.
- «Увеличить количество маршрутов»: ждёт решения Арины.

## Не реализовано (P1)

Интеграция с МИС, подпись врача, хранение в РФ и 152-ФЗ, мультивизитная сводка по версиям шкал, перевод на английский. Прототип не является медицинским изделием.
