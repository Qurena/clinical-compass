# Клинический компас: сайт

Распакуйте архив, перейдите в папку clinical-compass и запустите Node.js версии 22.13 или новее.

- Windows: запустите start.bat.
- macOS / Linux: выполните `npm start` и откройте http://localhost:3000.
- `npm test`: автоматические проверки; два теста HADS-A помечены TODO, потому что утверждённой формы в КЛК нет.
- Для новой демонстрационной базы укажите новый DB_PATH; начальные синтетические данные загружаются только в пустую базу. Не используйте настоящие медицинские данные.

Врач видит сводку изменений, записи дневника, сообщения и пробелы лекарственных данных. По рекомендации показаны основания, данные для уточнения и решение врача. Анне добавлены отдельные синтетические история, дневник и сообщение. Блок тревоги сохраняет ответы без расчёта балла HADS-A. Положительный пункт 9 сразу открывает C7 и сохраняет частичные ответы; такая анкета не начисляет искры.

Обычная и ранняя отправка используют токен против дублирования. До подтверждения запрос сохраняется в sessionStorage вкладки, чтобы повторить после перезагрузки. При закрытии вкладки до подтверждения данные могут быть потеряны. При отсутствии сети врач не получает сигнал до успешной отправки. Контакт врача — заглушка, реальной экстренной службы нет.

Серверные и программные проверки выполнены. Среда не предоставила браузер с доступом к серверу: реальный интерфейс на 390 и 1440 px, повторные клики, визуальную вёрстку, реальное переключение и обрыв сети в браузере необходимо проверить на устройствах.

В пакет входят только сайт, тесты, конфигурации и медицинский контекст. Постер и видео не менялись и сюда не входят.

## Запуск для показа с телефона (27.10)
1. Двойной щелчок по `start.bat`. В окне будет адрес `http://localhost:3000` и адреса для других устройств, например `http://192.168.0.71:3000`.
2. Один раз от администратора запустите `deploy\open-lan-firewall.ps1`: без этого телефон не достучится до ноутбука.
3. Телефон должен быть в той же Wi-Fi сети. Откройте адрес из окна сервера, нажмите нужную кнопку демо-входа.
4. Автозапуск при входе в Windows: `deploy\install-autostart.ps1`.
Подробности: `deploy/README.md`. Найденные и исправленные ошибки: `docs/BUGFIX_REPORT.md`.
