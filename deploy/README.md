# Локальный запуск на ноутбуке (Windows)

1. Установите Node.js 22 или новее (у вас 24 — подходит). Зависимостей нет, `npm install` не нужен.
2. Двойной клик по `start.bat` в корне папки → сайт на http://localhost:3000 (перезапускается сам при падении, база в `data\compass.db`).
3. Чтобы сайт поднимался при включении ноутбука: правый клик по `deploy\install-autostart.ps1` → «Выполнить с помощью PowerShell». Создаётся задача «ClinicalCompass» (запуск при входе в Windows, права администратора не нужны). Удалить: `Unregister-ScheduledTask -TaskName ClinicalCompass -Confirm:$false`.
   Запасной вариант: положить ярлык на `start.bat` в `shell:startup`.
4. Телефон/другой ноутбук в той же Wi‑Fi: `deploy\open-lan-firewall.ps1` от администратора, затем http://IP-ноутбука:3000 (`ipconfig`). Для демонстрации двух устройств: телефон — пациент, ноутбук — врач.
5. Демо-вход: кнопки на экране входа (врач, Мария, Анна, Игорь, Павел, Дарья). Все данные синтетические.
6. Сбросить данные: остановить сервер, удалить `data\compass.db`, запустить снова.

Если Windows просит разрешить сеть для Node — выберите «частные сети».
